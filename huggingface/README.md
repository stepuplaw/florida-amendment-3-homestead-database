# Florida Amendment 3 Homestead Database, 67 Counties (2026)

This Hugging Face copy holds `counties.csv`, `counties.json` and `schema.json`. The model and its documentation are in the [GitHub repository](https://github.com/stepuplaw/florida-amendment-3-homestead-database).

What Florida's Amendment 3 (November 3, 2026 ballot) would save homestead owners in each of the state's 67 counties, computed from every homestead parcel on the Florida Department of Revenue's 2026 preliminary roll (5,251,737 homesteads) and each county's 2025 non-school millage. School taxes do not change.

Compiled by [Kevin D. Klagge, Esq.](https://stepuplaw.com/about), a Florida estate planning attorney (Klagge Law, PLLC).
